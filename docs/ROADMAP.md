## 当前能力状态

### 1. 多游戏覆盖与智能路由
- **七游戏统一服务管线**：默认启用原神（`/ys`）、崩铁（`/sr`）、绝区零（`/zzz`）、方舟（`/ark`）、终末地（`/zmd`）、杀戮尖塔2（`/sts2`）、鸣潮（`/ww`）。
- **多级数据源与容灾分流**：
  - 明日方舟：优先 PRTS.Wiki（卡池一览与寻访规则），超时/异常自动回退 BWIKI。
  - 明日方舟：终末地：优先 AKEData 结构化数据表，未收录内容与特殊分节自动回退 BWIKI。
  - 杀戮尖塔2：直连 Spire Codex 公共 REST API，读取游戏官方简体中文数据；机制与攻略支持 STS2.INFO / STS2FRONT 双级中文源，不可用时回退英文内容。
  - 鸣潮：优先库街区官方攻略库 REST API（免登录，共鸣者养成、武器/声骸推荐、配队/加点、当期卡池唤取与版本活动），BWIKI 承载 1~90 级等级属性表、突破材料与共鸣链模板，主源无法结构化回答的问法自动平滑回退。
  - 原神 / 崩铁 / 绝区零：直连对应官方认证 BWIKI 知识库。

### 2. 自然语言理解与黑话智能归一
- **玩家黑话识别**：普攻（平A）、战技键位（E/Q技能）、全档位命座/星魂/影画/潜能、专武/满精/1+1 社区简写；杀戮尖塔2 进阶难度（A10/N10）、敲/锻造/休息等动作黑话归一。
- **修饰语前置保护**：智能区分前后缀，输入「满命魈」「专三能天使」等前置修饰语时不破坏实体名，精准检索；输入「纳西妲一命效果」等后置提问时精准定位对应分节。
- **角色配装深度穿透**：原神与星铁自动穿透「<角色>/攻略」子页面，打通圣遗物、遗器、词条与配装推荐；原神武器技能精炼多档数值（`/` 隔开）支持按指定档位精确投影。
- **卡池与UP时效对齐**：提问「现在UP什么」「寻访保底」时自动重定向至各游戏卡池聚合总览页；注入提问时刻北京时间（UTC+8）严格筛选进行中卡池，避免过期幻觉。
- **比较问法、条目对比与低置信度自愈**：跨角色对比智能引导分别查询；缺少疑问词的自然提问（如「胡桃语音」）未命中时自动回退大模型重抽实体；新增 `wiki_compare` 工具与杀戮尖塔2同类条目字段差异与胜率对比。

### 3. 排版展现与出图能力
- **本地高精度证据卡片**：技能、材料、属性等具体问题，文字概览后附带游戏主题色 PNG 证据卡片；数值与描述分列对齐，关键条件完整展现；杀戮尖塔2 WebP 图像发送前自动转为 JPEG。
- **全内置小米 MiSans 字体**：Regular 与 Medium 双字重随包分发，无需宿主机装配系统字体；支持在数据目录自定义覆盖。
- **智能立绘与去重**：仅名称或身份类查询附带立绘，分节追问与证据卡片不重复发图；同一会话窗口（600 秒）内图片自动去重防刷屏。

### 4. 架构韧性与独立模型
- **独立模型配置**：WebUI 专属 `model_provider` 下拉配置项；留空跟随会话聊天模型，指定后专供维基概览；调用异常时自动回退会话模型，仍失败平滑降级为“原文摘录”。
- **多层有界缓存**：SQLite 持久化缓存（64 MiB 上限，LRU 淘汰），并发相同请求自动合并；杀戮尖塔2 独立 1 小时缓存适应 EA 期频繁变动；上游 429 退避冷却与 BWIKI 间歇性 WAF 自动重试。
- **多轮会话与追问**：候选编号 2 分钟、条目追问 10 分钟上下文记忆，按用户与会话物理隔离。

## 后续演进规划

1. **AKEData 终末地数据覆盖深化**
   - 持续跟进终末地测试版本数据表变动，适配信赖/潜能动态数值占位符映射。
   - 补充武器详细属性成长表、基建效果与获取途径的结构化解析，逐步降低对 BWIKI 备用源的依赖。
2. **在线数据源监控与防漂移（Drift Detection）**
   - 在 CI 定时任务中扩充独立 AKEData 在线测试用例，真实核对主源可用性，避免备用源成功掩盖主源失效。
   - 增强 PRTS「卡池一览」表格结构变化与 Spire Codex / 中文攻略源可用性检测。
3. **真实环境部署与平台验收**
   - 在各主流 AstrBot 部署环境（Linux、Docker、Windows）中实机复核后台热重载、跨平台字体渲染一致性与图片传输延迟。
4. **长文本与移动端卡片体验优化**
   - 探索超长技能描述在证据卡片中的折行排版优化，进一步降低极端长文本被省略的概率。
   - 评估绝区零「意象影画」与杀戮尖塔2多分支长事件在卡片中的空间分配。
5. **词库与社区术语持续扩容**
   - 收集玩家真实高频搜索语料，动态扩充新干员/新角色/新卡牌别名与俚语映射。
   - 持续跟进各游戏大版本更新带来的新系统与专有名词。
6. **杀戮尖塔2 数据与攻略源持续跟踪**
   - 紧密跟进 Spire Codex 官方 API 在 Early Access 期间的字段变更与数据重构，维护 `data_version` 兼容性。
   - 监控 STS2.INFO 与 STS2FRONT 中文攻略源的连通性与反爬防护，确保双级容灾机制平滑稳定。
7. **鸣潮库街区官方数据源与活动合集持续跟踪**
   - 持续监控库街区官方 wiki 首页「角色/武器活动唤取」侧边栏模块格式变动，确保当期卡池时间与 UP 条目正常解析。
   - 跟踪大版本更迭时「活动合集」目录树节点的变化规律，确保版本活动动态定位机制长期有效。
