# 游戏百科 · AstrBot 插件

[![CI](https://github.com/KirishimaRin/astrbot_plugin_gamewiki/actions/workflows/ci.yml/badge.svg)](https://github.com/KirishimaRin/astrbot_plugin_gamewiki/actions/workflows/ci.yml)

查询原神、崩坏：星穹铁道、绝区零、明日方舟、明日方舟：终末地与杀戮尖塔2的角色、卡牌、遗物、技能、材料、配装、卡池和任务资料。支持命令查询与大模型工具调用，向用户返回中文概览、证据卡片与来源链接。明日方舟优先 PRTS，终末地优先 AKEData，杀戮尖塔2使用 Spire Codex，其余三款游戏使用 BWIKI。所有公开维基查询均直接调取公开接口，无需 API Key、UID 或游戏账号凭据。

当前版本：**v0.3.1**；作者：**KirishimaRin**；插件标识：`astrbot_plugin_gamewiki`。持续改进计划见 [ROADMAP](docs/ROADMAP.md)。

## 功能特性

### 玩家黑话与口语识别
- **修饰语前置保护**：智能区分修饰语与实体位置。对于「满命魈强度怎么样」「一命那维莱特面板」「专三能天使」等前置修饰语，前缀保持原样以供检索，避免被改写为“命之座魈”导致条目搜索失败；后置提问（如「纳西妲一命效果」）则正常归一至对应方面词。
- **全游戏通用口语**：支持「平A / 平a → 普攻」；键位「E技能 / Q技能」按游戏映射为战技与爆发技能；支持全档位命座与阶数表述（「0命~6命 / 满命」、「0魂~6魂 / 满魂」、「0画~满画」、「精一/精二」、「专一~专三」、「0潜~满潜」）。
- **装备简写与评价词过滤**：识别「专武」（按游戏映射为武器/光锥/音擎）、「满精」（精炼5）以及社区简写「1+1 / 6+5 / 0+1」（拆分命座与精炼，角色页关联命座分节）；自动过滤「毕业」（如「胡桃毕业面板」提取为「胡桃面板」）。
- **时效指代统一**：将「今天 / 现在 / 最新 / 这期 / 本期」统归为「当前」，便于匹配维基中的「（当前）」时效分节。

### 当期卡池与时效资讯聚合
- **卡池关键词重定向**：提问命中 up / UP池 / 角色池 / 武器池 / 光锥池 / 音擎池 / 混池 / 集录 / 定轨 / 常驻 等词汇时，自动重定向至各游戏的卡池聚合总览页（原神「祈愿」、星铁「跃迁」、绝区零「调频」；明日方舟按问法分流至 PRTS「卡池一览」与「寻访规则」；终末地暂无聚合页）。
- **时钟校准与时效判定**：生成概览时传入提问时刻的北京时间（UTC+8），根据卡池起止时间严格筛选正在进行中的卡池；间歇期注明最近一场排期，避免给出过期活动信息。
- **道具条目白名单**：明日方舟的「寻访凭证」「寻访数据契约」等道具条目加入白名单，不触发卡池重定向。

### 角色配装与攻略子页深挖
- **自动读取攻略子页**：针对 BWIKI 原神与星铁角色主页中配装部分多为跳转链接的情况，当提问涉及圣遗物、遗器、词条、配装推荐时，自动读取「<角色>/攻略」子页面（绝区零在主页内联）；子页不存在时平滑回退主页。
- **词条建议并入装备分节**：页面无独立“词条”分节时，自动并入圣遗物/遗器分节提取建议。
- **武器精炼数值投影**：针对原神武器技能以斜杠内联多档数值（如 `20%/25%/30%/35%/40%`）的排版，提问「精炼3效果」或「精2」时，按对应档位投影提取单个数值。

### 本地证据卡片与内置字体
- **纯本地排版出图**：技能、材料、属性等具体问题，在简明文字概览后附带游戏主题色 PNG 证据卡片；描述与数值分列呈现，保留技能等级、单位与约束条件。
- **内置 MiSans 字体**：随包自带小米 MiSans Regular 与 Medium 字体及官方许可协议，开箱即用，无需服务器安装字体；支持在数据目录放入字体文件覆盖。

### 独立模型配置与回退容灾
- **独立模型设置**：后台提供 `model_provider` 配置项。留空时跟随 AstrBot 会话当前聊天模型；也可自由指定服务提供商专用于维基概览。
- **双重回退兜底**：独立模型调用失败时，自动回退至会话当前模型；仍失败则降级为纯文本格式的原文摘录。
- **管理诊断**：运行 `/ys doctor` 可查看插件模型配置、回退发生次数、缓存状态与网络退避详情。

### 交互引导与多轮追问
- **查询开始即时提示**：提问通过限流后，插件优先发送“正在查询<游戏>百科，请稍候…”，避免长时间搜索与大模型推理期间静默等待；可通过配置项 `query_notice` 自由开启或关闭。
- **比较类提问引导**：提问跨角色对比（如「纳西妲和万叶练谁」）时，提示“百科单次查询一个条目”，并在回答后附上分别查询的两条命令建议。
- **未命中输入重试**：遇到「胡桃语音」这类缺少疑问词的自然输入，本地未命中条目时自动回退大模型重抽实体，减少误报。

## 安装方法

### 1. AstrBot 插件市场安装（推荐）
本插件已发布至 AstrBot 官方插件市场。在 AstrBot WebUI 管理面板中进入「插件管理」->「插件市场」，搜索 `游戏百科` 或 `astrbot_plugin_gamewiki`，点击安装即可。

### 2. 通过仓库链接安装
在 AstrBot 管理面板的「插件管理」页面选择通过链接安装，填写本仓库地址：

```text
https://github.com/KirishimaRin/astrbot_plugin_gamewiki
```

安装后启用插件，确认依赖安装完成即可。

### 3. 离线 ZIP 安装
从 Release 页面下载构建好的 `astrbot_plugin_gamewiki-v*.zip`，在 WebUI「插件管理」中上传安装。

### 4. 本地开发与源码调试
将本仓库放置于 AstrBot 的 `data/plugins/astrbot_plugin_gamewiki/` 目录中，在 WebUI 中重载插件。构建与调试方法见 [开发说明](docs/DEVELOPMENT.md)。

## 命令与交互

默认命令前缀为 `/`（若在 AstrBot 中自定义了前缀，按配置使用）。插件注册了 **6 个游戏入口主命令**：

| 入口指令 | 对应游戏 | 查询示例 |
|---|---|---|
| `/ys` | 原神 | `/ys 纳西妲突破需要什么材料`<br>`/ys 现在UP什么`<br>`/ys 护摩之杖精炼3效果`<br>`/ys 胡桃圣遗物推荐` |
| `/sr` | 星穹铁道 | `/sr 流萤晋阶材料`<br>`/sr 黄泉星魂效果`<br>`/sr 乱破遗器推荐`<br>`/sr 跃迁保底机制` |
| `/zzz` | 绝区零 | `/zzz 艾莲怎么获取`<br>`/zzz 简意象影画`<br>`/zzz 驱动盘词条搭配` |
| `/ark` | 明日方舟 | `/ark 能天使专三材料`<br>`/ark 银灰精英化`<br>`/ark 寻访保底是多少`<br>`/ark 寻访凭证怎么获得` |
| `/zmd` | 终末地 | `/zmd 汤汤技能`<br>`/zmd 武器图鉴`<br>`/zmd 干员基础属性` |
| `/sts2` | 杀戮尖塔2 | `/sts2 燃烧之血`<br>`/sts2 打击`<br>`/sts2 铁甲战士初始卡组`<br>`/sts2 树叶史莱姆招式` |

### 常见查询模式
- **条目基础介绍**：`/ys 钟离` ➡️ 返回角色定位、神之眼、基础简介与立绘。
- **具体属性查询**：`/ys 纳西妲 元素战技10级倍率` ➡️ 提取数值，生成简短文字并附带证据卡片。
- **卡池与机制查询**：`/sr 现在UP什么` 或 `/ark 寻访规则` ➡️ 对齐时效，呈现当期卡池或机制说明。
- **武器精炼查询**：`/ys 护摩之杖精5` ➡️ 自动从技能说明中提取第 5 档精炼数值。
- **角色对比提问**：`/ys 钟离比起万叶哪个好` ➡️ 提示单次查询一个条目，并给出分别查询的指令。

### 多轮对话与追问
默认开启上下文支持（`conversation_enabled`）：
1. **候选列表选择**：查询存在同名歧义时给出候选列表，2 分钟内直接回复序号（如 `2`）或发送 `/ys 2` 即可确认词条。
2. **上下文分节追问**：确认角色后 10 分钟内，可直接追问“突破材料呢？”“一命效果呢？”，无需重复输入角色全名。
3. **会话隔离**：上下文按会话与发送者严格隔离，多用户同时查询互不干扰。

### 管理员指令
管理员（拥有 AstrBot 管理权限）可通过任意游戏入口执行以下管理指令：
- `/ys help`：查看帮助与说明。
- `/ys stats`：查看各游戏上游请求数、缓存命中与合并、解析计数与限流窗口。
- `/ys clear-cache`：清理本地 SQLite 缓存、解析结果与缩略图临时文件。
- `/ys session on / off / status / reset`：控制当前会话是否允许使用百科查询，状态即时持久化。
- `/ys doctor`：本地运行自检，诊断目录读写、缓存健康度、模型提供商状态、回退统计及网络退避状态。

## AI 工具调用

若在 AstrBot 中启用了大模型对话与工具调用（Function Calling），可在人格中配置以下工具：

| 工具名 | 参数 | 功能说明 |
|---|---|---|
| `wiki_search` | `query`、`question`、`game` | 搜索指定游戏的百科条目，自动提取最匹配分节并返回候选列表 |
| `wiki_read` | `page_id`、`section`、`question`、`game`、`source` | 按搜索结果补充读取详细分节（双数据源游戏须填写 source） |
| `genshin_wiki_search` | `query`、`question` | （兼容旧版）原神专属搜索，等价于 `game=ys` |
| `genshin_wiki_read` | `page_id`、`section`、`question` | （兼容旧版）原神专属补读 |

AI 工具路径全面接入黑话归一化逻辑，大模型对话中调用工具同样支持「平A」「0命」「专武」「UP池」等表述转换。

## 配置说明

在 AstrBot WebUI 的「插件配置」中可按需调整：

| 配置项 | 默认值 | 说明 |
|---|:---:|---|
| `games` | `["ys", "sr", "zzz", "arknights", "zmd", "sts2"]` | 启用的游戏列表。可按需删减，空列表自动回退为全部启用 |
| `model_provider` | `""` (留空) | 插件专属模型：留空跟随会话聊天模型；下拉指定后固定使用该模型，失败自动回退会话模型 |
| `model_timeout_seconds` | `20` | 单次大模型调用超时（2–60 秒） |
| `overview_chars` | `250` | 命令模型概览目标字数（150–500 字，附证据卡片时正文自动精简） |
| `reply_brief_chars` | `350` | 降级纯文本原文摘录字数（名称查询，200–1500 字） |
| `reply_question_chars` | `750` | 降级纯文本原文摘录字数（问题查询，300–2000 字） |
| `query_notice` | `true` | 查询开始后先回复一条“正在查询…”，避免搜索与模型调用期间长时间静默；关闭后只在结果返回时发送 |
| `conversation_enabled` | `true` | 是否开启候选编号选择与多轮追问上下文（候选2分钟、条目10分钟） |
| `image_reply` | `true` | 仅在名称/立绘查询时附带立绘；卡片类与具体分节查询不重复发送 |
| `search_cache_seconds` | `600` | 搜索结果本地缓存有效期（0–3600 秒） |
| `page_cache_seconds` | `21600` | 正文与分节本地缓存有效期（0–86400 秒，默认 6 小时） |
| `user_cooldown_seconds` | `5` | 单用户调用冷却时间（0–60 秒，0 为关闭；管理员豁免） |
| `user_rate_limit` | `6` | 单用户每分钟最大查询次数（0–60，0 为关闭） |
| `global_rate_limit` | `30` | 插件全局每分钟最大查询次数（0–300，0 为关闭） |
| `upstream_concurrency` | `2` | 对各百科站点的最大并发抓取数（1–8） |
| `upstream_pace_seconds` | `0.3` | 请求发出步频间隔（0.1–2 秒），避免突发高频触发站点反爬 |
| `aliases` | `[]` | 自定义角色昵称映射，格式为 `["白菜=纳西妲", "龙王=那维莱特"]` |
| `enabled_sessions` | `[]` | 会话白名单，留空表示全放行，格式为 `平台:类型:会话ID` |
| `debug_log` | `false` | 开启后在后台输出分节匹配评分与耗时统计 |

## 卡片字体与版权说明

- 插件默认内置小米科技 **MiSans** 字体（Regular 与 Medium 字重），随安装包自带官方授权协议，在本地通过 Pillow 渲染，无需宿主机配置系统字体。
- 字体文件遵循随附的 [MiSans 字体许可协议](assets/fonts/MiSans-LICENSE.pdf)，独立于本项目的 MIT 协议。
- 如需替换字体，将字体文件放入数据目录的 `fonts/` 下（支持 `.ttf` 与 `.otf`），重载插件即可生效。

## 缓存与防护机制

- **持久化 SQLite 缓存**：位于 `data/plugin_data/astrbot_plugin_gamewiki/wiki-cache.sqlite3`，LRU 淘汰上限 128 条记录 / 64 MiB，重启不丢失。
- **请求合并与退避保护**：并发相同请求自动合并；遇到 429 自动按照 `Retry-After` 全局冷却对应主机；针对 BWIKI 间歇性 WAF（HTTP 567）内置退避重试机制。
- **图片去重**：同一会话窗口（600 秒）内同一张立绘不重复发送，避免刷屏。

## 常见问题

**Q：插件加载失败或报错？**  
A：检查 Python 版本是否为 3.10+，检查核心依赖是否安装。插件兼容 Pillow 10~13，如遇依赖冲突请检查宿主环境中的冲突包。

**Q：AI 没有调用维基工具？**  
A：确认大模型支持 Function Calling，且当前人格中已勾选 `wiki_search` 与 `wiki_read` 工具。建议先通过 `/ys` 等命令测试插件链路是否畅通。

**Q：查询提示 403 / 429 或连接超时？**  
A：说明宿主机到对应百科站点（BWIKI / PRTS / AKEData）的网络出现抖动或触发了短时访问频率限制，稍候重试即可，也可在配置中适当调大请求间隔 `upstream_pace_seconds`。

**Q：别名无法识别？**  
A：插件内置了主流别名（如草神、岩王爷、雷神、水龙王等）。遇到小众昵称，可在 WebUI 配置项 `aliases` 中添加映射（如 `["牢大=..."]`）。
